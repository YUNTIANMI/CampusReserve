# CampusReserve
## 校园场地预约微信小程序——需求规格说明书

版本：v1.0  
项目定位：软件工程作品集项目  
核心方向：微信小程序开发  
后端定位：提供小程序所需的核心 API，不追求复杂后端架构

## 1. 项目概述

CampusReserve 是一个校园场地预约微信小程序，用于模拟自习室、研讨室、摄影棚、球场等资源的预约场景。

项目重点展示：
- 微信小程序页面开发
- 页面导航与生命周期
- 组件化开发
- 用户交互与状态处理
- 网络请求
- 微信登录
- 本地缓存
- 预约业务
- 真机调试
- Git 版本管理

后端仅承担用户、资源、预约所需能力。

## 2. 核心用户流程

登录 → 浏览资源 → 查看详情 → 选择日期 → 查看时间段 → 选择时间 → 创建预约 → 查看我的预约 → 取消预约

## 3. 用户角色

### 普通用户
- 登录
- 浏览资源
- 查看详情
- 查看可预约时间
- 创建预约
- 查看自己的预约
- 取消自己的预约

第一版不实现管理员小程序端。

## 4. 功能需求

### 4.1 首页
展示项目入口、资源分类、热门/推荐资源、加载状态、空状态。
点击资源进入列表或详情。

### 4.2 资源列表
- 查看资源
- 按类型筛选
- 点击查看详情
- 处理 loading / success / empty / error

资源类型示例：
- 自习室
- 研讨室
- 摄影棚
- 球场

### 4.3 资源详情
展示：
- 图片
- 名称
- 类型
- 地点
- 容量
- 描述
- 当前状态

提供：
- 日期选择
- 可用时间段
- 预约入口

切换日期后重新获取该日期可预约时间。

### 4.4 时间段
示例：
- 09:00-10:00
- 10:00-11:00
- 11:00-12:00
- 14:00-15:00
- 15:00-16:00

状态：
- `AVAILABLE`
- `BOOKED`
- `DISABLED`

用户只能选择 `AVAILABLE`。

### 4.5 创建预约
输入：
- `resourceId`
- `date`
- `startTime`
- `endTime`

提交前检查：
1. 用户已登录
2. 资源存在
3. 日期合法
4. 时间合法
5. 时间段仍可用

成功：提示并跳转。  
失败：显示明确原因。

### 4.6 我的预约
显示：
- 待使用
- 已完成
- 已取消

每条包含资源、日期、时间、状态。

### 4.7 取消预约
用户可以取消自己的有效预约。
取消后状态为 `CANCELLED`，时间段恢复可用。
不得取消其他用户预约。

### 4.8 登录
第一版实现基础微信登录流程：
小程序获取登录凭证 → 后端识别用户 → 返回登录状态 → 保存必要用户信息。

不做复杂账号体系。

### 4.9 本地缓存
允许缓存用户基础信息、登录状态、最近筛选条件。
禁止无意义长期保存敏感信息。

## 5. 页面结构

- `pages/index`
- `pages/resource-list`
- `pages/resource-detail`
- `pages/my-bookings`
- `pages/booking-detail`
- `pages/login`（必要时）

## 6. 交互要求

主要页面至少处理：
- Loading
- Success
- Empty
- Error

禁止：
- 白屏
- 无限加载
- 点击无反馈
- 请求失败无提示

## 7. 非功能要求

### 易用性
核心路径尽量保持：
浏览资源 → 查看详情 → 选时间 → 预约

### 稳定性
接口失败时给出清晰提示，并允许重新加载。

## 8. MVP

包含：
- 首页
- 资源列表
- 资源详情
- 日期/时间选择
- 登录
- 创建预约
- 我的预约
- 取消预约

不包含：
- 管理员后台
- AI 推荐
- Redis
- MQ
- 支付
- 微服务
- 实时聊天

## 9. 成功标准

用户可以完整完成：
登录 → 浏览资源 → 查看详情 → 选择日期 → 选择时间 → 创建预约 → 查看预约 → 取消预约。

页面、数据、状态、异常均正常。
