# CampusReserve
## 开发阶段计划

版本：v1.0

## 总原则

核心目标：
> 展示完整的微信小程序开发流程。

重点：
小程序 UI → 页面/导航 → 组件化 → 生命周期 → 请求 → 登录 → 资源 → 预约 → 状态处理 → 真机测试 → 工程整理

后端只实现核心 API。

# AI 协同开发流程

每个 Phase：

```text
Phase
 ↓
拆 Task
 ↓
Codex 读取项目状态
 ↓
分析任务
 ↓
提出计划
 ↓
开发
 ↓
测试
 ↓
开发者验收
 ↓
更新 PROJECT_MEMORY.md
 ↓
Git Commit
```

禁止跨阶段一次性实现大量功能。
